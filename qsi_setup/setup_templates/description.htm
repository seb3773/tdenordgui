Welcome to tdeNordgui Setup

tdeNordgui is a native, ultra-lightweight graphical interface for the NordVPN Linux CLI, built specifically for the Trinity Desktop Environment (TDE) and Q4OS.

Key Features:

  • Ultra-Fast & Lightweight: Pure native C++/TQt3 client (< 1 MB) consuming minimal memory and starting instantly.
  • Real-Time Daemon Sync: Direct gRPC communication with the local nordvpnd daemon for live connection states.
  • Dynamic System Tray: Persistent status icon in the kicker panel with full right-click control menu.
  • Advanced Security Settings: Manage Threat Protection, Custom DNS, and connection protocols directly from the GUI.
  • Native TDE Experience: Clean desktop integration, single-instance management, and system notifications.
